# Открытые задачи

Порядок = приоритет. Закрытая задача убирается отсюда и уходит в `journal/` с числами.

## 1. Сеть 2.0

Сделано: интерполяция позиции и `yaw` чужих игроков и существ (D21): клиент хранит два снапшота, `alpha` по измеренному интервалу, скачки > 5 м не сглаживаются. Осталось:

- предсказание локального игрока по последнему подтверждённому состоянию вместо `lerp` в снапшоте;
- jitter buffer ввода;
- дельта-снапшоты (сейчас каждый снапшот — полный клон мира);
- живой `ReliableChannel`.

Цена текущего сглаживания — ~50 мс задержки отображения чужих сущностей; это норма для интерполяции с задержкой, но стоит помнить при правках ближнего боя.

## 2. Отсечение

`zn_scene::select_lod` теперь используется (`zn-client`: 25 м для игроков, 30 м для существ, дальше — куб), но frustum/distance culling'а нет: рисуется всё, что попало в снапшот. Мипмапы есть только на одном пути загрузки текстур.

## 3. Боёвка: следующий слой

Сделано: рейкаст, раздельные хитбоксы тела и головы ×3 (D16), PvP, стены, XP, респавн. Осталось:

- оружие как предмет с боезапасом (сейчас `equipped_weapon` — просто строка);
- урон по своим при `ExtractionSuccess` (сейчас эвакуация без риска);
- отдача и разброс — потребует согласия клиента и сервера по детерминизму.

## 4. Тесты серверных обработчиков

`zn-net`, `zn-sim`, `zn-content`, `zn-core` покрыты. Слабое место — `zn-server` (нужна БД) и `zn-client`.

## 5. Петля сессии: что осталось

Сделано: экраны `Menu`/`Playing`/`Dead`, панель инвентаря по Tab, `egui-winit` (D20). Осталось: выбор снаряжения перед рейдом (упирается в оружие как предмет), экран результата рейда с вынесенным лутом, настройки (чувствительность, громкость).

## 6. glTF

Нормали трансформировать inverse-transpose; несколько примитивов на файл.

## 7. Мёртвый код

`ChunkManager`, `ChunkEvent`, `load_chunk_async`, `ReliableChannel` — реализовать или удалить. `chunk_of` используется только тестом.

## 8. Физика на сервере

Интегрировать `PhysicsWorld` вместо упрощённого движения; заодно понадобится ООББ для повёрнутых узлов карты (сейчас `obstacles()` считает AABB без учёта поворота).
