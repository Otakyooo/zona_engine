## Первый прогон CI и остаточный дефект

Ран `42188758780` — **success** (8m02s): `build-launcher` ✓ 1m28s, `build-rust` ✓ 7m36s (Versions/Format/Clippy/Test/Build/Count tests), `self-check` ✓ 20s, `release` пропущен. `ZONA_TEST_COUNT=144` дошёл до job, `ci/artifacts/tests.json` в CI = `unchanged`.

**Но автокоммит появился:** `ff73151 docs(roadmap): regenerate from artifacts [skip ci]` (CHANGELOG.md, 1 insertion / 6 deletions). Цикла нет — новых ранов не было, `[skip ci]` сработал, — но критерий «ноль автокоммитов» не выполнен.

Причина: `renderChangelog()` читал живые `git tag`. Локально 13 тегов, на `origin` 12 — **`v0.1.7` (bd69bfb) есть только локально**. В CI он не зафетчился, CHANGELOG.md перегенерировался без секции v0.1.7 → diff → автокоммит. Пушить `v0.1.7` нельзя: workflow подписан на `tags: ['v*']` и запустил бы release-job для старой версии.

Исправление: список релизов перенесён в `ci/roadmap.yaml` → `releases` (12 тегов, реально существующих на remote); `renderChangelog(data)` берёт его вместо `git tag`; `loadRoadmap()` требует непустой `releases`; `AGENTS.md` фиксирует правило «не добавлять тег в releases, пока его нет на origin». Это убирает зависимость генерируемых файлов от того, какие теги зафетчены в конкретном окружении.

Фикс закоммичен как `5ab5466` (`fix(ci): pin the changelog release list…`) и запушен. Локально: 4 проверки cargo зелёные, 144 теста, генератор `unchanged` во всех трёх режимах.

**Вторая ловушка:** ран для `5ab5466` не создался (`gh api …/actions/runs?head_sha=5ab5466` → `total_count = 0`). Причина — в теле коммита дословно упомянут маркер пропуска CI в квадратных скобках; GitHub проверяет весь commit message, а не только subject, и молча отменяет workflow. Записано в `PITFALLS.md`. Лечение: этот коммит `docs(memory):` с чистым сообщением запускает CI заново; дальше контролируем, что `self-check` выводит `generated docs unchanged` и не создаёт автокоммит.

Итог по версии: продукт остался `0.3.1`, протокол 8, релизов и тегов не создавалось. F0 закрыта; следующий шаг — F1 (144 → 145 тестов).
