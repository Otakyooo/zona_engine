## Починка Фазы 0 перед коммитом (второй проход)

Аудит нашёл, что первая версия петли была бы шумной и не ловила бы регрессии. Исправлено:

- `ci/self-check.js`: убран `HEAD` из всех генерируемых файлов; `CHANGELOG.md` теперь строится только по тегам с фильтром `[skip ci]`, а «не вошло в релиз» уходит в неотслеживаемый `ci/artifacts/CHANGELOG-unreleased.md`; добавлены `ZONA_TEST_COUNT` (число тестов из `build-rust`), `previous` и проверка «было → стало»; при генерации обновляется отслеживаемый `ci/artifacts/tests.json`; описание входов приведено к реальности, чтение метрик/`OPEN.md`/`GUI_CHECKLIST.md` явно отнесено к F3; удалён мёртвый код.
- `.github/workflows/ci.yml`: шаг `Count tests` и `outputs.test_count` в `build-rust` (один тёплый билд вместо второго холодного), `self-check` получает число через `ZONA_TEST_COUNT`, добавлены `needs`, `concurrency`, guard `head_commit != null`, убран `git pull --rebase`, diff-guard коммитит ещё и `tests.json`.
- `.gitignore`: `ci/artifacts/*` + `!ci/artifacts/tests.json` (иначе исключение файла внутри заигнорированного каталога не работает).
- `ci/roadmap.yaml`: F0 → `done`; F1 скорректирована под реальность кода — блокировка игры после `Welcome` (`guard StartRaid` + `ui.add_enabled`), отказ логируется клиентом, серверная метрика перенесена в F2 вместе с `Handshake`, `verifyUpdateCodeSignature` перенесён в F6 (нужен сертификат и `CSC_LINK`, сейчас `signAndEditExecutable: false`). Протокол остаётся 8, `ClientPacket` не меняется.
- `AGENTS.md` / `MEMORY.md`: синхронизированы clippy, записи о кэшах `target/` и `node_modules/`, описание петель и статусов артефактов. Устаревший `.kilo`-план перенесён в `.kilo/plans/archive/` с пометкой `Superseded`.

**Решение (D, без номера до согласования):** отслеживаемые документы должны быть чистой функцией неизменяемых источников (теги, версия, протокол, число тестов, `ci/roadmap.yaml`). Причина: любой HEAD/дата/`unreleased`-коммит в `ROADMAP.md` или `CHANGELOG.md` заставляет CI создавать автокоммит на каждый push. Следствие: статусы и критерии меняются только через `ci/roadmap.yaml`.
