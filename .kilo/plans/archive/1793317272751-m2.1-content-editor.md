# План: M2.1 — контент-пайплайн и редактор (расширение)

## Цель

Довести контент-пайплайн до production-ready: текстуры (PNG + mipmaps), офлайн-baker (упаковка мешей/текстур), LOD-генерация, асинхронный стриминг чанков, 3D-viewport в редакторе. Результат: большие карты загружаются без фризов, редактор показывает сцену в 3D.

## Контекст

M2 завершён: редактор (eframe, hierarchy/inspector/save/load/play), glTF-импорт, RON-сцены, базовый стриминг (фильтрация по дистанции). M1.5 добавил текстуры (PNG → wgpu) и освещение. Текущие пробелы:
- Текстуры загружаются только в клиенте, редактор не показывает 3D.
- Нет офлайн-baker: glTF парсится при каждом запуске.
- LOD не генерируется (только выбор по дистанции).
- Стриминг синхронный (блокирует тик).

## Зафиксированные решения

- Текстуры: PNG/JPEG через `image` (уже есть), генерация mipmaps на CPU при загрузке. KTX2/Basis — backlog (требует внешних инструментов).
- Baker: консольная утилита `zn-baker` в `zn-tools` (бинарь). Вход: glTF/PNG → выход: `.zpak` (bincode: меш + текстура + LOD-уровни).
- LOD: упрощение мешей через `meshopt` (если доступен) или простое прореживание (каждый N-й треугольник). 3 уровня: high (100%), mid (50%), low (25%).
- Стриминг: асинхронная загрузка чанков через `tokio::spawn` + канал `mpsc`. Клиент получает `ChunkLoaded { coord, nodes }` события.
- Редактор viewport: рендер сцены через `zn-render` в eframe (wgpu backend). Использовать `egui_wgpu` paint callback или отдельный render pass.
- Gizmos/snap-to-grid: отложены в M2.2 (требуют сложной UI).

## Затронутые границы

- `crates/engine/zn-assets`: baker API, mipmaps, кэш текстур.
- `crates/engine/zn-scene`: async chunk streaming, LOD-выбор, `ChunkEvent`.
- `crates/zn-tools`: бинарь `zn-baker`, расширение editor (viewport, play-in-editor).
- `crates/zn-client`: async streaming, рендер LOD-уровней.
- `Cargo.toml`: добавить `meshopt` (опционально), `tokio` (уже).

## Порядок работ

### 1. Текстуры и mipmaps (zn-assets)
- `load_texture(path) -> Result<LoadedTexture, _>`: decode PNG → RGBA8, генерировать mipmaps (halving).
- `LoadedTexture { width, height, mip_levels: Vec<Vec<u8>> }`.
- Кэш текстур в `AssetCache` (уже есть `AssetCache`, расширить).

### 2. Офлайн-baker (zn-tools/zn-baker)
- Новый бинарь `[[bin]] name = "zn-baker"`.
- CLI: `zn-baker --input scene.gltf --output scene.zpak`.
- Читает glTF, извлекает меш + текстуры, генерирует LOD, упаковывает в `.zpak` (bincode).
- `zpak` формат: header (magic, version) + mesh data + texture data + LOD offsets.

### 3. LOD-генерация
- Функция `generate_lod(mesh: &LoadedMesh, ratio: f32) -> LoadedMesh`: прореживание треугольников (каждый N-й).
- 3 уровня: 1.0, 0.5, 0.25.
- Хранить в `LoadedMesh` как `lod_levels: Vec<LoadedMesh>`.

### 4. Асинхронный стриминг (zn-scene)
- `ChunkManager` расширить: `request_load(coord)` → отправляет в канал.
- `ChunkEvent::Loaded { coord, nodes }`, `ChunkEvent::Unloaded { coord }`.
- Клиент: tokio runtime в отдельном потоке, принимает события через `mpsc::Receiver`.

### 5. Редактор viewport (zn-tools/editor)
- Добавить 3D-viewport: рендер сцены через `zn-render` (wgpu) в eframe.
- Использовать `egui::painter` для overlay (gizmos — позже).
- Play-in-editor: запуск клиента с текущей сценой (уже есть).

### 6. Тесты
- Unit: mipmap generation (размеры уменьшаются).
- Unit: LOD (количество треугольников уменьшается).
- Unit: chunk_of / select_lod (уже есть).
- Интеграционный: baker создаёт .zpak, клиент загружает.

### 7. Валидация
- `cargo build --workspace`, `cargo test --workspace`, `cargo clippy --all-targets -- -D warnings`.
- Ручной smoke: редактор показывает 3D-сцену, baker создаёт .zpak, клиент загружает большую карту без фризов.

## Риски

- `meshopt` крейт может не компилироваться на Windows — fallback на простое прореживание.
- Асинхронный стриминг усложняет синхронизацию (race conditions) — использовать каналы и single-threaded обработку событий в главном потоке.
- eframe + wgpu viewport: интеграция egui и wgpu требует тщательной настройки (render pass, bind groups).
- KTX2: отложен, так как требует внешних инструментов (toktx).

## Вне области M2.1

- KTX2/Basis-текстуры.
- Gizmos и snap-to-grid (M2.2).
- Undo/redo.
- Полноценный ассет-пайплайн с hot-reload.
