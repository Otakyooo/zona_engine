# План: Деплой сервера на VPS (192.168.0.255)

## Цель

Развернуть `zn-server` на локальном VPS так, чтобы он работал непрерывно (watchdog + автозапуск), принимал подключения тестеров по LAN, и клиенты могли подключаться без локального сервера.

## Контекст

Сервер (`zn-server`) собирается и запускается локально. Деплой-скрипты (`deploy/watchdog.ps1`, `deploy/README.md`) уже созданы. Порты настраиваемые (`--bind`, `--port`). БД — SQLite по умолчанию (`zona.db`), миграции при старте.

## Зафиксированные решения

- Сервер: VPS `192.168.0.255`, порты TCP 7777 (auth) + UDP 7778 (game).
- Бинарь: `target/release/zn-server.exe`.
- БД: SQLite `C:\zona\zona.db` (создаётся автоматически).
- Автозапуск: Task Scheduler (при загрузке ОС) + watchdog-скрипт.
- Firewall: открыть порты 7777 TCP и 7778 UDP.

## Порядок работ

### 1. Сборка релизного бинаря
- `cargo build -p zn-server --release`
- Проверить, что `target/release/zn-server.exe` существует.

### 2. Копирование на VPS
- Создать папку `C:\zona\` на VPS.
- Скопировать `zn-server.exe` в `C:\zona\`.
- (Опционально) скопировать `zona.db` если есть сохранённые данные.

### 3. Настройка firewall на VPS
- Открыть порт 7777 TCP: `New-NetFirewallRule -DisplayName "ZONA TCP" -Direction Inbound -Protocol TCP -LocalPort 7777 -Action Allow`
- Открыть порт 7778 UDP: `New-NetFirewallRule -DisplayName "ZONA UDP" -Direction Inbound -Protocol UDP -LocalPort 7778 -Action Allow`

### 4. Настройка watchdog
- Скопировать `deploy/watchdog.ps1` на VPS в `C:\zona\`.
- Создать задачу в Task Scheduler: запуск `powershell -File C:\zona\watchdog.ps1` при загрузке ОС (с правами администратора, скрытое окно).

### 5. Запуск и проверка
- Запустить watchdog вручную или дождаться автозапуска.
- Проверить процесс: `Get-Process zn-server`.
- Проверить лог: `C:\zona\server.log`.
- Проверить подключение: `cargo run -p zn-client -- --server 192.168.0.255` (с локальной машины).

### 6. Валидация
- Сервер отвечает на подключение (клиент получает `Welcome`).
- Игроки могут двигаться и видеть друг друга.
- При убийстве процесса сервера watchdog перезапускает его в течение 10 с.
- После перезагрузки VPS сервер стартует автоматически.

## Риски

- Порты 7777/7778 могут быть заняты другими программами на VPS — использовать `--port` для смены.
- Firewall может блокировать UDP — проверить правила.
- Task Scheduler может не запустить скрипт без прав администратора — настроить «Выполнять с наивысшими правами».
- SQLite-файл должен быть доступен для записи (права на папку `C:\zona\`).

## Вне области

- Публичный IP / домен (только LAN).
- PostgreSQL (используем SQLite).
- Мониторинг/алерты.
