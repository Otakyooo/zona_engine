# План: Выбор папки установки + запуск сервера

## Цель

Дать игроку выбрать папку установки игры (через диалог), сохранять выбор, переносить уже скачанные файлы при смене папки. Также запустить dev-сервер для локального тестирования.

## Контекст

Лаунчер сейчас жёстко использует `userData/game` как папку установки. Пользователь хочет выбирать место установки. Сервер нужно запустить для тестирования.

## Зафиксированные решения

- Выбор папки: диалог `dialog.showOpenDialog` (Electron) через IPC.
- Хранение: `localStorage` в renderer + дублирование в `userData/settings.json` (main process).
- Миграция: при смене папки — автоматически перенести `zn-client.exe` и `version.json`.
- Fallback: если папка недоступна/не выбрана — `userData/game`.
- Сервер: запускается отдельно (watchdog или ручной запуск).

## Затронутые границы

- `launcher/main.js`: динамический `gameDir`, IPC `get-install-dir`, `set-install-dir`, `pick-install-dir`.
- `launcher/preload.js`: экспорт новых API.
- `launcher/renderer.js`: UI (кнопка «Изменить папку», отображение текущей).
- `launcher/index.html`: элементы настроек.

## Порядок работ

### 1. main.js: динамический gameDir
- Заменить `const gameDir = path.join(userData, 'game')` на функцию `getGameDir()` читающую из `userData/settings.json`.
- Если файл отсутствует или невалиден — fallback `userData/game`.
- `ensureDir(getGameDir())`.

### 2. IPC-обработчики
- `get-install-dir`: вернуть текущий путь.
- `pick-install-dir`: открыть `dialog.showOpenDialog({ properties: ['openDirectory'] })`, вернуть выбранный путь (или null).
- `set-install-dir`: принять новый путь, создать папку, перенести файлы из старой (если есть `zn-client.exe`/`version.json`), сохранить в settings.json, вернуть `{ ok, path }`.

### 3. preload.js
- Экспортировать `getInstallDir`, `pickInstallDir`, `setInstallDir`.

### 4. UI (index.html + renderer.js)
- В футере или настройках: строка «Папка установки: <path>» + кнопка «Изменить».
- При клике: вызвать `pickInstallDir`, если выбрано — `setInstallDir`, обновить отображение.
- При первом запуске (нет settings.json) — автоматически показать диалог выбора.

### 5. Миграция файлов
- В `set-install-dir`: если в старой папке есть `zn-client.exe` — `fs.renameSync` (или copy+delete) в новую.
- Перенести `version.json` тоже.

### 6. Запуск сервера
- Выполнить `cargo run -p zn-server` (или собранный бинарь) в фоновом процессе.
- Для VPS — watchdog.

### 7. Валидация
- Лаунчер открывает диалог выбора папки при первом запуске.
- После выбора — скачивает/запускает игру из новой папки.
- При смене папки — файлы переносятся.
- Сервер запущен и принимает подключения.

## Риски

- Диалог выбора папки может не работать без GUI (headless) — только в Electron main process (ок).
- Миграция файлов при занятом файле (игра запущена) — проверять, что клиент не запущен.
- Путь с пробелами/кириллицей — корректно экранировать (Node path handles).
